# Modern Reference Presentation

This directory preserves the pre-vNext Modern Viewer as reference presentation code.

- It is not the current implementation authority.
- It consumes the shared published Boundary at the site root (`/manifest.json`, `/data/**`, `/maps/**`).
- Compatibility with future Boundary evolution is best-effort only.
- Current Viewer development happens under `../current/`.
- Legacy freeze is isolated under `../legacy/` and must not be modified by normal deployment.
